# Bubble 0.0.60

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Changes

- List GPT-6.1 Sol for ChatGPT sign-ins. The account model catalog is now
  requested as Codex client 0.159.0, the minimum version the backend lists it
  for. `BUBBLE_CODEX_CLIENT_VERSION` still overrides the claimed version.
- Give each ChatGPT model catalog request its own 15-second timeout, so a slow
  proxy no longer starves the fallback path. A failed refresh now reports why
  each path failed (HTTP status, timeout, or malformed payload) and how long it
  took.
- The edit tool matches `oldText` exactly. The looser fallback matchers
  (trimmed, unescaped, normalized-line, Markdown table, whitespace, and smart
  line) were removed. CRLF/LF line endings and a leading BOM are still
  normalized for comparison and restored on write, including mixed line endings
  within one file. A miss returns the closest matching line so the model can
  re-read and retry.
- Advertise a budgeted skill catalog (names and one-line descriptions) in the
  system prompt, kept across prompt rebuilds. Context usage counts only the
  skills the prompt carries.
- SDK: turn-scoped `hostTools` and `skillPaths`, inputs interrupted before a
  turn is admitted are preserved, and stop waits for persistence. Images
  returned by tools are surfaced as observations.
- Tool screenshot observations are no longer treated as user turns for rewind,
  compaction boundaries, session titles, or checkpoints.
- `--cwd` is resolved to an absolute path and becomes the process cwd.
- Security: grep applies the read tool's sensitive-path check to every matched
  file, so an explicit hidden root such as `~/.aws` no longer exposes
  credentials. Deny rules parse wrapper options that take an argument (`sudo -u
  root rm -rf x` is now caught). The LSP service accepts in-project names that
  start with two dots.
- Terminal UI: the tasks pane keeps the current turn's finished work, resets
  its history view when new activity starts, and hands keyboard focus back when
  closed from the status bar.

## Behavior note

Edits whose `oldText` only matched through a fallback (for example, different
indentation or escaped characters) now fail with a closest-line hint instead of
applying. SDK hosts that relied on fuzzy matching should send the exact text.
