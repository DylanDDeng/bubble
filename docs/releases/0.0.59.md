# Bubble 0.0.59

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Changes

- Add OpenCode Zen Space Bunny Free with model metadata, free pricing, reasoning
  effort selection, Chat Completions routing, and reasoning replay for tool calls.
- Retry Space Bunny's specific opaque upstream 422 rejection with bounded,
  cancellation-aware backoff. Other validation errors remain nonretryable;
  diagnostics retain request-shape counts rather than prompt text.
- Expose a session replay cursor and settled completion events so SDK hosts can
  track turns and queued follow-ups. Add an optional replay retention window;
  the default remains unlimited and active readers retain their unread events.
- Prevent long thinking transcripts from triggering repeated terminal wake
  recovery, reduce collapsed reasoning layout costs, and restore terminal images
  after a real wake.
- Include accumulated model catalog, interrupted-stream recovery, session
  persistence, context compaction, shared OAuth, and permission fixes since
  0.0.58.

## SDK migration note

`SdkSessionEvent.terminal` now also marks successful turns with
`{ kind: "completed" }`. In 0.0.58, its presence meant failure or cancellation.
Consumers must inspect `terminal.kind` before reading `terminal.message` or
displaying an error:

```ts
if (record.terminal && record.terminal.kind !== "completed") {
  console.error(record.terminal.message);
}
```

A completed turn can already have a queued successor. Check
`getSessionRunState(sessionId).active` before marking the session idle.
Snapshot `handle.latestSequence` before sending a turn, then use
`handle.eventsFrom(cursor)` to observe only subsequent work.

Hosts opting into `sessionEventRetention` must restore durable session history
when an old replay cursor expires. Omitting this option preserves unlimited
process-local replay.
